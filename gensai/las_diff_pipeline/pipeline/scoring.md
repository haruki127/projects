# 建物や地形が受けた被害の大きさを基準に合わせて評価、スコアリングするためのプログラム。
# 1『準備と設定』ツールボックスとログの準備
# 2『基準に合わせて点数化』数値をボーダーライン（基準値）と比較して、点数に変換。絶対値としてボーダーラインを超えることに点数の追加
# 3『誤差やノイズを無視』「たまたまの誤差」か「本当に変化したか」を見極めて、誤差なら 0点 にする機能。あらかじめ決めた「これ以下は計測誤差（まぎらわしいノイズ）」という基準（lod95）と比べる。基準より小さくて怪しいデータは、容赦なく 0点 にリセット。最後に「全体の何％が確かなデータだったか」をログにメモ。
# 4『メイン処理：建物のデータを読み込む』1軒ごとの建物データから、最終的な被害スコア（0〜3）を決める準備
dz_mean: 建物の高さが平均して何メートル下がったか

dz_p95: 建物の高さが最大（上位95%）で何メートル下がったか

loss_ratio: 建物のデータがどれくらい消えてしまったかの割合

n_pre: 災害前にその建物に当たっていたレーザー（データ）の数

n_post: 災害後にその建物に当たっているレーザー（データ）の数
# 5『判定のルール（基準値）を決める』健康診断結果をジャッジするための「赤点ライン」を設定
